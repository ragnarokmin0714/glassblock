# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/), and this project adheres to
[Semantic Versioning](https://semver.org/).

## [1.4.0]

### Added
- **Generic cosmetic filtering from upstream** (`hide-generic.css`, generated by
  `tools/gen-cosmetic.py`): ~14,200 domain-less `##` element-hiding selectors
  from EasyList and EasyList China, emitted as plain CSS. Until now every one of
  the ~30,000 cosmetic filters in those lists was discarded, because the
  converter only handles network rules. No new permission was needed — the
  extension was already injecting a stylesheet on every page.
  - Selectors are emitted in chunks of 100. A CSS selector list is
    all-or-nothing, so one selector Chrome rejects would otherwise take the
    whole sheet down with it.
  - `#@#` un-hide exceptions cannot be expressed in a global stylesheet, so any
    selector carrying one is dropped — erring toward showing an ad rather than
    breaking a page.
  - Domain-scoped (~15,900) and procedural (`:has-text()` and friends) filters
    are still out of reach; the first needs per-site sheets, the second a DOM
    engine.
- **Pause on this site** in the popup: writes a dynamic `allowAllRequests` rule
  for the current hostname at priority 100 and reloads the tab. Replaces the old
  workflow of hand-editing `rules_custom.json` and reloading the extension.
  Costs the `activeTab` permission, which is needed only to learn the hostname.
- **Match counter** in the popup, via `getMatchedRules`. Costs the
  `declarativeNetRequestFeedback` permission, which Chrome grants to unpacked
  extensions only; the popup degrades quietly without it.
- Dark-mode styling for the popup.

### Changed
- `tools/update-lists.sh` now regenerates `hide-generic.css` too, and enforces a
  **lower bound** on every generated artefact (1,000 rules per list, 5,000
  cosmetic selectors) alongside the existing 30,000 upper bound. `curl --fail`
  catches an HTTP error and curl catches a truncated transfer, but a server
  answering 200 with a maintenance page passed both and would have installed a
  gutted ruleset silently.
- README now documents each permission and its exact scope, replacing the
  "never requests permission to read your page content" line that `activeTab`
  made inaccurate.

### Known deviation
- `$important` block filters are emitted at priority 2, the same as `@@`
  exceptions, and declarativeNetRequest lets `allow` win ties — so `$important`
  does not override exceptions the way Adblock Plus specifies. Measured impact:
  4 rules across all three lists, all in EasyPrivacy. Left alone deliberately;
  the fix (priority 3) is one line if it ever matters.

## [1.3.0]

### Added
- **EasyList China** ruleset (`rules_easylistchina.json`, ~6,000 rules), with
  its own popup toggle. EasyList/EasyPrivacy are Western-focused and barely
  touch mainland ad networks, so Chinese-language sites were largely unfiltered.
- `tools/update-lists.sh` now refreshes EasyList China alongside the other two.

### Fixed
- Custom ruleset now also blocks `main_frame` requests. Without it, a popunder
  that navigated a new tab straight to a known ad domain sailed through, since
  only sub-resource types were listed.

## [1.2.0]

### Added
- Icon set: master `icons/icon.svg` and exported `icon16/48/128.png`, wired into
  the manifest (`icons` and `action.default_icon`).
- Logo mark shown in the toolbar popup header.

### Changed
- Renamed the extension to **GlassBlock**.

## [1.1.0]

### Added
- Full **EasyList** and **EasyPrivacy** coverage, converted from Adblock Plus
  filter syntax to native `declarativeNetRequest` rules
  (`rules_easylist.json`, `rules_easyprivacy.json`).
- `tools/convert.py` — converter that turns filter lists into MV3 rule JSON,
  batching plain domain rules to stay well under Chrome's static-rule limit.
- `tools/update-lists.sh` — one-command refresh that downloads, converts, and
  rule-count-checks the lists atomically before replacing the shipped files.
- Per-ruleset on/off toggles in the toolbar popup (Custom / EasyList /
  EasyPrivacy), each taking effect immediately.

### Changed
- Renamed `rules.json` to `rules_custom.json` to sit alongside the two
  upstream-derived rulesets.
- All UI text, code comments, and documentation translated to English.

## [1.0.0]

### Added
- Initial release: minimal Manifest V3 ad blocker using
  `declarativeNetRequest` for network blocking and a content-script CSS file
  (`hide-ads.css`) for cosmetic element hiding.
- Hand-written `rules.json` covering core ad domains.
